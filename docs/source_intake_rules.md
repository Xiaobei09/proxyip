# 源接入规则（公开抽象）

本仓只发布数据与契约；**真实源自托管于私有 PCB 仓库**，公开树一律使用代号/占位符/环境变量/secrets。

## 接入 checklist

1. 独立性 / 可达性：主 URL + ≥2 镜像；超时、重试、退避；网络请求 ≤30s。
2. 字段可解析：离开页面/接口仍能提取完整字段；失败隔离记录 `source_stats.json`/`source_history.json`。
3. 频率与体量：尊重配额；活跃维护与 License/ToS 兼容；UA/Referer 合规，不绕过验证码/反爬、不超频。
4. 验证：通过 `download_proxies.py` + `analyze_sources.py`；提交前 unittest 全绿。
5. 可一键回滚：停用时记原因与日期；泄露则立即回滚并全面扫描。
6. 私有性：公开仓库零泄露真实名称/URL/凭证/实现/配置/日志；扫词表 grep 必为空。

## 回滚步骤

- 停用：移出注册表，保留代号与文档纸迹。
- 泄露：旋转凭证、回滚提交、扫描历史/日志、重新审计。

## 接入证据

- 新源必须记录在 docs/scripts.md（公开仅占位符）。
- 需提供含超时/重试/降级/退避的注册表条目与针对性测试。
